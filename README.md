## 🚀 التشغيل محليًا

### 1. المتطلبات

- Node.js 18 أو أحدث.
- حساب Supabase للتخزين الدائم للجلسة إذا أردت تشغيل التخزين السحابي.
- رقم WhatsApp مخصص للبوت.

### 2. تثبيت المشروع

```bash
git clone https://github.com/SALEH-AL-KHULAIFI/Whatsapp-bot.git
cd Whatsapp-bot
npm install
```

### 3. إعداد البيئة

```bash
cp .env.example .env
```

ضع القيم:

```env
SUPABASE_URL=
SUPABASE_SECRET_KEY=
```

**لا تضع ملف `.env` أو جلسة WhatsApp داخل GitHub.**

### 4. تشغيل البوت

```bash
npm start
```

في أول تشغيل ستظهر QR، ثم امسحها من:

**WhatsApp → الأجهزة المرتبطة → ربط جهاز**

بعد نجاح الربط، يحاول المشروع الحفاظ على جلسة المصادقة حسب إعداد التخزين.

## ☁️ النشر على خادم

يمكن تشغيل المشروع على خادم Node.js يدعم عملية طويلة التشغيل واتصال WebSocket وتخزينًا دائمًا للجلسة.

الخطوات العامة:

1. اربط المستودع بخدمة استضافة Node.js.
2. اجعل أمر البناء/التثبيت:
   ```bash
   npm install
   ```
3. اجعل أمر التشغيل:
   ```bash
   npm start
   ```
4. أضف متغيرات البيئة:
   - `SUPABASE_URL`
   - `SUPABASE_SECRET_KEY`
5. تأكد من وجود تخزين دائم مناسب للجلسة.
