# Arabic WhatsApp Bot 🇦🇪🇸🇦🇾🇪

بوت واتساب عربي مفتوح المصدر، يعمل محليًا بدون AI وبدون Gemini أو خدمات ذكاء اصطناعي خارجية.

## الهدف
مشروع محادثة عربي واسع يدعم العربية الفصحى ومجموعة كبيرة من اللهجات العربية، مع نظام مطابقة محلي سريع ومكتبة ردود قابلة للتوسعة.

## اللهجات
المشروع يفصل بيانات اللهجات في مجلد `dialects/`، ويحتوي سجلًا رقميًا في `DIALECTS.md` يوضح الدول والمجموعات واللهجات المدعومة.

الدعم مصمم على مستوى **اللهجة/المنطقة** وليس على أساس أن لكل دولة لهجة واحدة؛ فالحدود السياسية لا تطابق دائمًا الحدود اللغوية.

## الخصائص
- ⚡ ردود محلية سريعة.
- 🤖 لا يعتمد على AI.
- 🔐 الإعدادات السرية عبر `.env`.
- 📚 مكتبة ردود كبيرة.
- 🧠 مطابقة وتطبيع للنص العربي.
- 🌍 دعم عربي متعدد اللهجات.
- 🧩 بنية قابلة لإضافة لهجات وعبارات جديدة.
- 📱 يعمل مع WhatsApp Web عبر Baileys.

## التشغيل
1. ثبّت Node.js 18+.
2. نفّذ:
```bash
npm install
```
3. انسخ:
```bash
cp .env.example .env
```
4. ضع قيم Supabase في `.env`.
5. شغّل:
```bash
npm start
```
6. امسح QR من WhatsApp عند أول تشغيل.

> لا تضع مفاتيح Supabase أو ملفات جلسة WhatsApp داخل Git.

## النشر
يمكن تشغيل المشروع على خادم Node.js يدعم WebSocket والاتصالات طويلة المدى. يجب حفظ جلسة المصادقة في تخزين دائم، أو استخدام طبقة التخزين المضمنة في المشروع.
